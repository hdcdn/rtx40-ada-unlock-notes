# RTX 40 系（Ada）解锁资料整理

基于 `JustAResearcher/gpu-unlock-ada` 主仓库（v1.1.1）逐文件核对后的整理，不引用社媒二手数字。

## 一句话结论

FP16 / BF16 / TF32 的成倍提升是真的（有同卡 A/B 与逐位校验）；**FP8 没有提升**；"40 系全系支持"是夸大——Linux 模块只启用了 3 个 device ID。

## 逐卡数据

| 显卡 | 状态 | 原厂 | 解锁后 | 倍数 |
|---|---|---|---|---|
| RTX 4090 | 正式支持 | 165.6 | **331.6 TF/s** | 2.00× |
| RTX 4070 Ti SUPER | 实验·单卡 | 95.0 | **189.9 TF/s** | 2.00× |
| RTX 4060 Ti 16G | 实验 | — | — | 无同卡对比 |
| RTX 4070 Ti (AD104) | 仅 Windows | 84.08 | 151.43 | +80.1% |
| 4080 / 4080S / 4070 / 4060-8G | 未支持 | — | — | 仓库零验证 |

## 三处辟谣

1. "全系 40 系都支持" → 实际只有 `10de:2684` / `2705` / `2805`
2. "FP8 翻倍" → 实测 FP8 GEMM 59.326 → 59.495 TF/s（+0.3%）
3. "指令级 2× = 应用 2×" → 4090 真实 cuBLAS GEMM 只涨 12–34%
